# MVP1 - alcance implementado

## Objetivo
Habilitar un flujo base de captura y validacion de ideas de negocio con estado trazable del caso.

## Incluye
- Endpoint de salud.
- Endpoint de intake de idea.
- Endpoint de consulta de ideas.
- Endpoint de decision de validacion de negocio.
- Estado de caso con etapas de intake y business validation.
- UI para capturar ideas y visualizar estado, score de valor y score de riesgo.
- Base multilenguaje: canonicidad en espanol (`es`) y soporte operativo inicial para `es`, `en`, `pt`.

## Fuera de alcance en MVP1
- Validacion tecnica.
- Company Context Engine.
- Ingestion documental.
- Telemetria avanzada.
- Admin Center.
