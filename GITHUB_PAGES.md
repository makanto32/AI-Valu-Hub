# GitHub Pages

Este repositorio está configurado para servir archivos HTML directamente a través de GitHub Pages.

## Activar GitHub Pages

1. Ve a **Settings** → **Pages**
2. En "Build and deployment", selecciona:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `root`
3. Click en **Save**

Después de 1-2 minutos, tu sitio estará disponible en:
**https://makanto32.github.io/AI-Valu-Hub/**
