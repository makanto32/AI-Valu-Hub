Arquitectura Detallada

Plataforma empresarial de descubrimiento semántico con orquestación basada en skills, servicios de Azure e inteligencia de sesión persistente.

Versión: 2.1 Alcance: Descubrimiento, Viabilidad, Arquitectura Objetivo Hosting: Azure Container Apps Persistencia: PostgreSQL + Blob + Azure OpenAI
Vista General Flujo End-to-End Componentes Datos y Persistencia Seguridad y Operación

Intención de diseño: mantener un flujo conversacional resiliente incluso si la persistencia cloud o el enriquecimiento por IA no están disponibles, habilitando comportamiento empresarial más rico cuando las dependencias de Azure están configuradas.

1. Vista General del Sistema

La solución combina una experiencia conversacional guiada para negocio, un orquestador determinístico de skills y enriquecimiento opcional por IA para pasar de una idea inicial a entregables de arquitectura.

Usuario de Negocio

Envía ideas mediante un flujo natural de conversación y recibe retroalimentación estructurada de inmediato.

Frontend React + Vite

Entrega la experiencia guiada, vistas por etapa y salidas de arquitectura embebidas.

Capa API FastAPI

Gestiona la orquestación, validaciones de política, persistencia y coordinación de herramientas.

Orquestador de Skills

Enruta la conversación al skill o agente correcto según etapa, rol y contexto.

Registro de Skills de Dominio

Cataloga skills de negocio, técnicos y de arquitectura con prompts e instrucciones versionadas.

Persistencia de Conocimiento

Almacena estado de sesión, contexto, decisiones y artefactos para enriquecimiento progresivo.

2. Flujo End-to-End

La conversación se mantiene orgánica, pero cada etapa es explícita y persistible.

Paso 1

Intake de Negocio

El usuario describe la oportunidad en lenguaje natural, en su idioma preferido.

→
Paso 2

Orquestación de Skills

Un enrutador determinístico selecciona el skill de negocio o técnico adecuado.

→
Paso 3

Validación y Estado

Las salidas estructuradas actualizan IdeaCase, resultado de validación y estado de compuerta.

Paso 4

Persistencia

Estado de la idea, bitácora de decisiones y artefactos se escriben en PostgreSQL y Blob.

→
Paso 5

Enriquecimiento de Contexto

Se recuperan y refrescan documentos relevantes, memoria de sesión y contexto de tenant.

→
Paso 6

Entregables de Arquitectura

La plataforma genera paquete de arquitectura, diagramas y resúmenes de sesión.

3. Componentes

Frontend

UI React + Vite con formularios guiados, interacciones conversacionales y vistas por rol.

  • Experiencia de intake de negocio
  • Experiencia de revisión técnica
  • Experiencia de administración y gobierno

API y Orquestación

FastAPI provee la capa de orquestación y expone endpoints para conversación, estado y artefactos.

  • Transiciones de etapa
  • Enrutamiento de agentes
  • Hooks de prompts y telemetría

Registro de Skills

Registro central de skills de dominio, prompts determinísticos e instrucciones versionadas.

  • Skill de Intake de Negocio
  • Skill de Viabilidad de Negocio
  • Skill de Validación Técnica
  • Compositor de Respuesta

Capa de IA

Modelos de Azure OpenAI / Foundry aportan razonamiento, resumen y generación localizada de respuestas.

  • Detección de idioma
  • Canonicalización
  • Localización de respuestas
La arquitectura privilegia una sola superficie conversacional para el usuario, mientras internamente enruta a skills y agentes especializados.

4. Datos y Persistencia

PostgreSQL Flexible Server

Almacena perfil de tenant, estado de ideas, decisiones, versiones de prompts y telemetría de agentes.

Azure Blob Storage

Persiste PDFs, exportables, evidencia, artefactos de arquitectura y paquetes conversacionales.

Azure AI Search

Indexa conocimiento contextual para recuperación híbrida semántica entre documentos y sesiones.

Inteligencia de Sesión Persistente

La memoria de sesión enriquece la conversación sin perder trazabilidad ni límites por etapa.

5. Seguridad y Operación

Managed Identity + Key Vault

Acceso seguro entre servicios Azure sin secretos embebidos.

Observabilidad

Application Insights y Log Analytics capturan latencia, costo, tokens, calidad y trazabilidad.

Gobierno de Prompts

Los prompts son versionados y auditables para mantener comportamiento estable entre despliegues.

Modelo de Despliegue

Azure Container Apps empaqueta frontend, API y workers en una huella cloud-native repetible.

6. Hoja de Ruta

7. Notas de Arquitectura

Por qué este diseño funciona

Mantiene la experiencia conversacional del usuario preservando estado machine-readable para operación empresarial.

Qué sigue abstraído

La implementación concreta de agentes, políticas de retrieval y telemetría avanzada queda para fases posteriores.
