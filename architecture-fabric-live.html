Integracion Microsoft Fabric para Dashboard Ejecutivo

Esta vista muestra el flujo operativo desde AI Value Hub en Azure Container Apps hacia un modelo semantico en Microsoft Fabric / Power BI, que alimenta el dashboard ejecutivo con metricas consistentes de ideas, estatus y costos.

Runtime: Azure Container Apps Data path: API snapshot -> Push dataset Analytics: Fabric semantic model Consumption: Executive Dashboard

Flujo End-to-End

La actualizacion semantica se ejecuta con scripts de sync y deja disponible un payload de metricas para consumo inmediato en la vista de dashboard.

Paso 1

AI Hub API (Azure)

La API consolida ideas por tenant y expone snapshot de metricas administrativas y ejecutivas.

Paso 2

Fabric Sync Script

El script toma snapshot JSON y publica una fila en la tabla semantica via API de Power BI.

Paso 3

Semantic Model (Fabric)

El dataset centraliza payload_json por tenant, con version de timestamp para trazabilidad.

Paso 4

Dashboard Ejecutivo

La UI consulta executeQueries DAX y renderiza KPIs: total ideas, aprobadas, ratio y costos.

Componentes Clave

metrics_provider.py

Selecciona provider local, semantic file o Power BI usando variables de entorno.

fabric_medallion.py

Genera capas bronze, silver y gold para trazabilidad y control de transformaciones.

scripts/fabric-provision-semantic.ps1

Provisiona workspace y semantic model para despliegue reproducible.

scripts/fabric-sync-semantic.ps1

Sincroniza snapshots desde API hacia dataset activo en Fabric.

Power BI provider activo Dashboard conectado a semantic model Sync programado opcional (no requerido para demo)
